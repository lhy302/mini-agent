## 一、核心项目定位

现代重型 Agent（如 DSH 完整版、Claude Code、各类基于 Node.js / Electron / Python 3.12+ / Docker 的开发智能体）功能强大，但在实际落地中常常面临两大约束：**安装门槛过高** 与 **严苛老旧环境无法运行**。

`dsh-mini` 的诞生正是为了精准解决这两个痛点：

### 1. 降低安装门槛：纯净环境中的“种子引导 Agent（Seed / Bootstrapper Agent）”
* **解决痛点**：在一台全新、干净、完全没有安装任何开发环境的电脑（Windows 10/11 或 Linux 桌面/服务器）上，想要安装部署完整的 Agent 系统，用户通常需要手动安装 Node.js/Python、配置环境变量、配置 Git、设置代理、解决安装依赖报错。对新手或临时调试场景而言，门槛极高。
* **破局方案**：`dsh-mini` 采用单文件分发，**双击即开，无需安装 Python 或任何外部运行时**。首次启动只需填入 API Key，用户直接对 AI 说一句话（例如：*“帮我在这台机器上下载并安装配置 DSH 完整版环境”* 或 *“帮我配置 Node.js 和 Git 环境”*），`dsh-mini` 即可凭借自带的持久化 Shell 执行能力与文件读写能力，**自主执行命令、下载工具包、配置环境变量，全自动帮你把完整的重型 Agent 环境搭建好**，充当真正意义上的“安装跳板与引导员”。

### 2. 严苛环境托底：无法安装正常 Agent 时的“最低限度保底 Agent（Fallback Agent）”
* **解决痛点**：在 Windows 7 老旧工控机、专用设备，或是系统崩溃无法启动的 **Windows PE 急救维护盘** 环境中，现代重型 Agent（依赖高版本 Node.js、WebView2、Chromium 或最新 C++ 运行库）**根本无法安装，甚至直接拒绝启动**。
* **破局方案**：针对这些被现代技术生态遗忘的严苛环境，专门推出了 `dsh-mini-win7深度定制版` 与 `dsh-mini PE急救定制版分支`。通过内嵌免依赖 PowerShell 7、集成 downlevel UCRT、降级兼容旧版 PowerShell 2.0/CMD，以及采用纯原生 Win32 Unicode 界面绕开老旧控制台编码崩溃，**在无法运行任何正规 Agent 的极端环境中，依然提供最低限度但稳定可靠的自主工具调用、系统运维、日志排查与文件救援能力**。

## 二、分支与适用环境

| 分支目录 | 适用环境 | 核心定位与特色 |
|---|---|---|
| **`dsh-mini/`** (主干) | Windows 10 / Windows 11 (64位) | **种子安装跳板 & 极简助手**：剥离旧版兼容包袱，单文件极小体积，无黑框 Win32 GUI，支持 pwsh/文件编辑/鼠标控制/屏幕截图多模态分析，用于快速自举装机或日常轻量运维。 |
| **`dsh-mini Linux专用分支/`** | Linux x86_64 (Ubuntu / Debian / CentOS / Arch 等) | **Linux 自动化安装跳板**：单文件二进制（`dsh-mini`）加桌面快捷方式（`.desktop`），零第三方依赖，双击即开，支持持久化 bash 会话，快速引导安装 Linux 上的完整开发环境。 |
| **`dsh-mini-win7深度定制版/`** | Windows 7 SP1 (64位) | **老旧系统保底 Agent**：内置稳定版 PowerShell 7 与 UCRT 运行库，彻底解决 Win7 下控制台编码崩溃、TLS 握手及 PS2.0 管道卡死问题，为老旧系统提供最后的智能体支持。 |
| **`dsh-mini PE急救定制版分支/`** | Windows PE / 微PE / 优启通 / 离线急救盘 | **系统救援保底 Agent**：自动感知 PE 维护环境，识别全盘与离线 Windows/ESP 引导，内嵌双引擎 Shell，支持离线修复与灾难救援，单文件直跑。 |

## 三、各平台快速上手

### 1. Windows 10 / Windows 11
1. 进入 `dsh-mini/` 目录，将 **`dsh-mini.exe`** 复制到任意位置（桌面、U 盘均可）。
2. 双击运行，首次启动自动弹出配置窗口，输入接口地址与 API Key。
3. 即可直接使用，或下达指令让它在这台干净的电脑上自动安装其它大型工具环境。

### 2. Linux 平台
1. 进入 `dsh-mini Linux专用分支/` 目录。
2. 双击桌面图标 **`dsh-mini.desktop`** 或在终端中执行 `./dsh-mini`。
3. 首次启动输入 API Key 与接口地址，即可在无 Python 依赖的纯净 Linux 系统中利用 bash 自主配置环境。

### 3. Windows 7 环境
1. 进入 `dsh-mini-win7深度定制版/` 目录。
2. 将 `dsh-mini.exe` 及相关文件拷入 Windows 7 机器，双击即可唤起原生界面，自动调用内嵌 pwsh。

## 四、核心功能与工具集

所有分支均严格围绕 **AI 自主执行** 打造，用户下达目标，模型自主规划并调用工具：

1. **持久化 Shell 执行（`pwsh` / `bash`）**：
   - 跨调用保持当前工作目录和环境变量，命令实时流式回显，支持超时打断。
   - 能够执行网络请求、软件静默安装包运行、系统配置脚本等，是实现“自动安装重型 Agent”的关键支撑。
2. **安全文件编辑器（`str_replace_editor`）**：
   - 支持文件查看、按块精确文本替换、新建文件及指定行插入，适合配置文件改写和代码修正。
3. **原生图形界面（GUI）**：
   - Windows 下采用纯原生 Win32 Unicode 控件（通过 ctypes 直调），彻底避免控制台黑框、编码崩溃及字体乱码；Linux 下采用原生轻量窗口。
   - 独立思维链折叠/展开、Token 消耗统计、离线自检工具窗口、会话保存与切换。
4. **多模态与辅助控制（Win10/11/Linux 主分支支持）**：
   - 支持自主读取本地图片（`read_image`）及屏幕截图（`take_screenshot`）送入多模态大模型分析；支持鼠标自主控制（`mouse_control`）。

## 五、快捷键与操作速查

| 按键 | 功能 | 说明 |
|---|---|---|
| `Esc` | 打断当前输出 / 停止命令 | 无论是在生成长文本还是在跑长时间脚本，一键停止 |
| `Enter` | 发送输入 | `Shift+Enter` 或 `Ctrl+J` 换行（支持多行输入） |
| `↑` / `↓` | 翻阅历史输入 | 快速调出上一次下达的安装命令或提示词 |
| `Ctrl+L` / `F7` | 新对话 | 自动保存当前会话并开启新对话 |
| `Ctrl+S` / `Ctrl+O` | 保存 / 打开会话 | 随时切换历史多任务上下文 |
| `F1` | 操作指南 | 查看详细图文与命令指引 |
| `F2` / `F3` | 接口配置 / 选择模型 | 在线扫描 `/models` 模型列表或修改 API Key |
| `F4` | 开关思考链 | 实时查看模型推理思考细节 |
| `F5` / `F6` | 离线自检 / 环境诊断 | 验证自身运行状态与底层 Shell 命令执行引擎 |

## 六、安全与网络说明

1. **隐私安全**：除直接与用户配置的兼容大模型网关（如 DeepSeek、OpenAI 等）通信外，**无任何第三方网络回传，无遥测统计代码**。
2. **杀软误报说明**：单文件打包的程序因包含解包引导层，在个别杀软下可能被启发式误判。本项目代码完全开源（见各分支 `dev/dsh-mini.py`），用户可按各分支文档随时用标准脚本重新编译打包。
