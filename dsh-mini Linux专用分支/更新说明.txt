  DSH 极简 Agent（dsh-mini）版本更新与 Linux 专用分支说明
  核心定位：纯净 Linux 环境的“种子引导安装跳板” & 轻量日常本地 Agent
======================================================================

【核心定位说明：彻底降低 Linux 下 Agent 的安装与环境配置门槛】
在全新的 Linux 机器或容器/服务器中，想要安装部署像 DSH 完整版、Claude Code 等
重型 Agent，用户往往需要先手动配置 Python 3.12+、Node.js 18+、Git、依赖库与代理，
操作链条长，门槛较高。
dsh-mini Linux 专用分支采用 PyInstaller 独立封装为单个可执行文件，无需安装 Python，
双击即开。用户只需启动它，对它说“帮我在这台机器上下载并安装配置好完整版 DSH 环境”，
即可由 dsh-mini 自主执行 bash 脚本、下载依赖包、自动配置环境，实现“自举安装”！

【v1.2.0 Linux 专用分支重构：全面跨平台迁移，单文件且双击即开】

1. 单文件 ELF 独立二进制封装（零依赖）：
   - 采用 PyInstaller 将 Python 3 运行时、Tkinter 图形系统与全量 Agent 逻辑封装为单个独立二进制 `dsh-mini`（约 14MB）；
   - 目标 Linux 机器（Ubuntu / Debian / CentOS / Fedora 等）无需安装 Python、无需配置任何虚拟环境，复制即可运行。

2. 桌面级双击即开体验：
   - 配套生成 `dsh-mini.desktop` 规范桌面入口与 `start-dsh-mini.sh` 终端快速启动器；
   - 在 GNOME、KDE、XFCE 等桌面环境中双击直接唤起图形主窗口，彻底摆脱必须打开黑框控制台的限制。

3. 原生图形界面（GUI）完整重构：
   - 针对 Linux 平台重构原生 Tkinter 图形界面（`DshTkGui`），与 Windows Win32 版保持 1:1 界面与操作手感对齐；
   - 菜单栏（会话、工具、设置、帮助）、流式对话输出（区分思考过程 `…` 与正文 `●`）、Token 用量与服务端前缀缓存统计；
   - 底部输入框智能自增高（2~8 行），支持 `Enter` 发送、`Shift+Enter` / `Ctrl+J` 换行；
   - 模态设置向导（F2）、在线模型选择列表（F3）、独立自检与诊断输出窗口（F5/F6）、图片分析弹窗（Ctrl+P）全部实现居中与事件捕获。

4. Linux 原生系统工具链适配：
   - 持久化 Shell（`pwsh / bash`）：基于 stdin 管道双向通信协议，Linux 下默认运行持久化 Bash 会话，`export` 环境变量、`cd` 目录、自定义函数跨轮长驻，支持超时打断与 oneshot 兜底；
   - 文件编辑器（`str_replace_editor`）：全面适配 Linux 根路径 `/` 校验，支持 UTF-8 / GBK 编码与 LF / CRLF 换行自适应；
   - 鼠标控制（`mouse_control`）：对接 Linux `xdotool`，支持坐标移动、点击、双击、长按释放、滚轮滚动与坐标查询，无 X11 环境自动仿真降级；
   - 截屏与视觉（`take_screenshot` / `read_image`）：对接 Linux 原生截图工具链（`scrot` / `gnome-screenshot` / `grim`），支持图片一键编码为 Base64 传入大模型进行多模态视觉感知。

5. 严苛质量与测试验证：
   - `check-constants.py` 静态属性检查 24 个类全部通过（0 隐患）；
   - 92 项离线综合自检（`--selftest`）全量断言 100% 通过（92/92 PASS）；
   - `pwsh/bash` 离线诊断通过，输出清晰；
   - GNOME 桌面环境真实双击运行与截图实测验证通过。

【历史版本演进记录】

v1.2.0 (Windows 版基线)：
- 升级为完全面向 Windows 10 / 11 现代环境；
- 界面彻底重构为纯 Win32 控件图形界面（无控制台黑框）；
- 引入鼠标自主控制（`mouse_control`）、截屏分析（`take_screenshot`）与自主读图（`read_image`）；

v1.1.5：
- 修复模型思考过程（reasoning_content）在历史消息中回传丢失导致服务端 KV Cache 击穿的致命缺陷；
- 兼容 llama.cpp / vLLM 的 `cached_tokens` 缓存统计。

v1.1.0 ~ v1.1.4：
- 增加 F1~F8 快捷键系统与常用操作菜单栏；
- 实现 `/models` 自动扫描与模型切换列表框；
- 增加会话持久化与多对话无缝切换能力。

v1.0.0 ~ v1.0.3：
- 初始版本发布，实现 DSH 极简 Agent 核心逻辑；
- 建立 pwsh 管道通信协议与单命令模式降级机制；
- 解决早期 Windows 控制台代码页崩溃问题。
