# DSH 极简 Agent（dsh-mini）v1.2.0 - Linux 专用分支

一个 **单文件、零依赖、复制即用、双击即开** 的 Linux 本地 Agent，功能与 DSH 的「极简模式（minimal）」完全对齐。

| 项目 | 内容 |
|---|---|
| 运行方式 | **单文件且双击即开**：桌面图标 `dsh-mini.desktop` 或直接执行 `dsh-mini` 单文件二进制 |
| 界面 | **原生图形界面**：菜单栏 + 对话区 + 多行输入框 + 状态栏，支持完整快捷键与模态对话框 |
| 可调用工具 | 全部面向 AI 自主调用：`pwsh/bash`（持久化 Shell 命令执行）、`str_replace_editor`（文件查看创建编辑）、`mouse_control`（鼠标自主操作）、`read_image`（自主读图送入多模态分析）、`take_screenshot`（自主截屏分析 GUI） |
| 接口协议 | 支持 OpenAI Chat Completions（文本与 Vision 多模态图片格式），可自由开启/关闭视觉支持 |
| 运行环境 | Linux x86_64（Ubuntu 22.04/24.04/26.04 等主流发行版），**目标机器无需安装 Python、无需任何第三方外部依赖** |
| 源码与构建 | 单文件 `dev/dsh-mini.py`（Python 3.8+），支持一键打包脚本 `dev/build-linux.sh` |

## 一、双击即开与快速上手

1. **双击即开**：
   - 直接双击桌面上的 **`dsh-mini.desktop`** 图标，即可直接启动图形界面。
   - 或者在文件管理器中双击单文件程序 **`dsh-mini`**（或执行 `./dsh-mini`）。
2. **首次启动自动弹出配置向导**：
   - 光标已在输入框内，输入「接口地址 base_url」（回车） -> 输入「API Key」（回车） -> 自动扫描并弹出模型列表（选择模型即可开始）。
   - 以后想修改配置可随时按 **F2**（接口与密钥）或 **F3**（选择模型）。
3. **输入与发送**：
   - 在底部的多行输入框内打字，按 **回车发送**（`Shift+Enter` 或 `Ctrl+J` 换行）。
   - 模型的**思考链过程**实时流式展示（以 `…` 开头，按 `Esc` 或点击「停止」按钮随时打断）。
   - 正文回复以 `●` 开头，每轮自动统计 Token 消耗与缓存命中情况。
   - 命令执行实时显示：`» bash/pwsh` + 命令 + 实时输出 + `√/× 完成/失败`。

## 二、快捷键与菜单

### 快捷键

| 按键 | 功能 |
|---|---|
| `Esc` | 打断当前输出 / 停止正在执行的命令（等同点「停止」按钮） |
| `Enter` | 发送消息；`Shift+Enter` 或 `Ctrl+J` 换行（多行输入） |
| `↑` / `↓` | 翻阅历史输入 |
| `Ctrl+C` | 有选中=复制；没选中=清空输入；空行再按一次=退出 |
| `Ctrl+D` | 退出程序 |
| `Ctrl+L` / `F7` | 新对话（自动保存当前对话并清空显示） |
| `Ctrl+S` | 保存当前会话 |
| `Ctrl+O` | 打开会话列表并切换 |
| `Ctrl+P` | 发送本地图片进行多模态视觉分析 |
| `F1` | 打开操作指南 / 帮助 |
| `F2` | 配置接口与密钥（向导模式） |
| `F3` | 在线扫描并选择模型 |
| `F4` | 切换显示/隐藏模型思考过程 |
| `F5` | 运行离线自检（92 项断言全部通过） |
| `F6` | 运行 Shell 环境诊断 |
| `F8` | 复制全部对话内容到剪贴板 |

### 菜单栏功能

* **会话(S)**：新对话 / 打开会话… / 保存会话 / 发送图片… / 复制全部 / 退出
* **工具(T)**：离线自检（92 项）/ pwsh/bash 诊断 / 打开诊断日志 / 打开界面日志 / 清空界面日志
* **设置(C)**：选择模型 / 接口与密钥 / 显示思考过程 / 支持图片输入（视觉开关） / 打开工作目录
* **帮助(H)**：操作指南 / 关于

## 四、从源码重新打包

如果修改了 `dev/dsh-mini.py`，可以直接使用一键打包脚本：

```bash
cd dev
bash build-linux.sh
```

脚本将自动执行：
1. 检查 Python 3 与 PyInstaller 环境；
2. 按照 `dsh-mini-linux.spec` 编译并封装为单文件可执行文件 `../dsh-mini`；
3. 赋予可执行权限并自动运行 92 项离线自检验证。
