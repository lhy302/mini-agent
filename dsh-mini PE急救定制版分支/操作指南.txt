========================================================================
 DSH 极简 Agent（dsh-mini）操作指南
 适用：Windows PE 维护环境、Windows 7 SP1 及以上（64 位）
 核心定位：PE 维护急救保底 —— 在无法安装正常 Agent 的环境提供最低限度运维能力
========================================================================

一、它是什么与核心定位
------------------------------------------------------------------------
一个单文件、零依赖的本地 Agent，功能与 DSH 的「极简模式」对齐。

【核心定位：Windows PE 维护环境下唯一的保底 Agent】
在 Windows PE（微PE、优启通、系统救援维护盘）环境中，由于缺少现代化运行时库
与组件，市面上所有的重量级 Agent 均完全无法安装或启动。
dsh-mini PE 急救定制版专为维护急救场景打造：
  1) 自动识别 PE 环境与挂载硬盘，自动探测离线系统目录与 ESP 引导分区；
  2) 内嵌免依赖 PowerShell 7 与 原生 CMD 降级双引擎，自动避开 RAM 盘写满；
  3) 免根证书校验模式，解决老旧 PE 证书过期无法联网连接大模型网关的问题；
在极端救援维护环境下，提供最低限度但稳定可用的 AI 自主离线运维、引导修复与文件编辑能力！

【面向 AI 自主的工具集】
  1) pwsh                持久 PowerShell 会话（支持 CMD 降级引擎）
  2) str_replace_editor  文件编辑器（view / create / str_replace / insert）
接口支持标准 OpenAI Chat Completions 协议（/chat/completions）。

程序只有一个版本：dsh-mini.exe，**图形界面**（无控制台黑框，双击出窗口）。
中文显示、字体、编码交给 Windows 控件处理，完全绕开控制台的各种老毛病；
界面上的每一行同时写进 dsh-mini-gui.log，排障最方便。

【快速上手】
  1) 双击 dsh-mini.exe。
     第一次使用（还没填过密钥）会**自动弹出设置**，不用记快捷键。
  2) 设置只有两步：填「接口地址」→ 回车 → 填「API Key」→ 回车。
     光标直接落在输入框里，可以直接打字或 Ctrl+V 粘贴；回车=确定、Esc=取消、
     Tab=切换控件。API Key 默认打码，勾「显示密钥」可核对；留空=保持原值。
     两项都确定后写入配置文件，并**自动接着弹出模型列表**（列表来自接口的
     /models，也可以直接在下面输入模型名；取消=保持当前模型）。
     以后想改随时按 F2（或菜单 设置→接口与密钥）。
  3) 按 F5 离线自检确认程序完好（81 项）；按 F6 做 pwsh 诊断
     确认命令执行功能可用（结果在独立窗口里，同时写入 dsh-mini-diagnose.txt）
  4) 在最下面的输入框里打字提问，回车发送
     · 模型的**思考过程**会以 … 开头实时显示（觉得它想歪了/死循环：按 Esc
       或点「停止」按钮打断）；正文以 ● 开头
     · F4（或菜单 设置→显示思考过程）可以随时开关思维链显示
     · 输出多了以后视图会**自动贴在下边缘**，最新一行始终看得见
  5) 命令执行会实时显示：» pwsh / 命令 / 实时输出 / √完成 或 ×失败，
     并把命令的真实输出贴在下面；同样的内容也写进 dsh-mini-gui.log

【多对话切换】
  菜单 会话(S)：
    新对话（Ctrl+L）     当前会话先自动保存，再开新对话
    打开会话…(Ctrl+O)    列出已保存会话（时间/模型/消息数），选中即切换
    保存会话（Ctrl+S）   手动保存当前对话
  退出程序时，有内容的对话也会自动保存一份，不会丢。

【Windows 7 兼容性（v1.0.1 起持续修复）】
  Win7 SP1 自带的是 Windows PowerShell 2.0，而且控制台是旧式实现，两个坑都踩过：
    · v1.0.1 修「一发命令就卡死」：旧版把命令塞进 "powershell -Command -" 的
      标准输入，在 2.0 上子进程毫无反应。现在改成自带 loader 协议 + 启动握手
      （默认 20 秒，含中文编码校验），握手不通就自动降级成「单命令模式」
      （每条命令一个独立进程，命令照常能跑，只是变量和当前目录不再跨调用保留）。
    · v1.0.2 修「一用命令程序就崩」：Win7 控制台按本机代码页（中文系统 cp936）
      严格编码，界面里的 "»"（工具调用行前缀）和 "›"（输入提示符）GBK 里没有，
      一打印就抛 UnicodeEncodeError 把整个程序带崩。现在输出层做了编码降级
      （表示不了的字符自动换成 ASCII 替代品），并新增崩溃日志
      dsh-mini-error.log（只在真出问题时生成）。
  想确认这台机器上的实际状态，运行：dsh-mini.exe --shellcheck


二、快速开始
------------------------------------------------------------------------
1. 把 dsh-mini.exe 复制到任意位置（U 盘、桌面都行，不需要安装 Python）。
2. 双击 dsh-mini.exe。
3. 首次启动会依次问三项，填完回车即可：

     接口地址 base_url : 例如 https://api.deepseek.com
     API Key           : 你的密钥
      模型名 model      : 例如 deepseek-chat

   - 地址按接口文档填即可，程序会自动补成 .../chat/completions：
       裸域名（如 https://api.deepseek.com）        -> 补 /v1/chat/completions
       以 /v1 /v2 结尾（如 https://x.com/v1）        -> 只补 /chat/completions
       带自定义路径（如 https://x.com/openai）       -> 只补 /chat/completions
       完整端点（含 /chat/completions）              -> 原样使用，不做任何改动
     所以遇到端点不在 /v1 下的网关，直接填完整端点最稳妥。
   - 密钥输入时显示成 *（不回显明文），可以直接按 Ctrl+V 粘贴，
     也可以在窗口里点鼠标右键粘贴，不用手打。粘贴后会自动去掉换行和首尾空格。
   - 模型名不做任何校验，接口没列出来的内测名字也能直接填。
   - 配置会保存在 exe 同目录，下次双击直接进入对话。

4. 想重新填：双击后执行命令 /exit 退出，再运行  dsh-mini.exe --setup
   （非交互环境也可以加 --force-wizard 强制跑一遍向导）


三、文件都放在哪
------------------------------------------------------------------------
默认是「便携模式」，所有文件都在 exe 同目录：

  配置文件   <exe目录>\dsh-mini.config.json
  会话记录   <exe目录>\sessions\session-日期-时间-随机.json
  打包临时   %TEMP%\_MEIxxxxxx（程序正常退出会自动删，被强杀会残留）

目录里有什么（整个文件夹可以复制到任何位置）：

  dsh-mini.exe           程序本体（图形界面，双击出窗口）
  操作指南.txt           本文件
  更新说明.txt           v1.1.5 改了什么、Win7 上怎么排查
  README.md              公开说明（怎么用、怎么从源码自己打包）
  dsh-mini.config.json   配置（地址/密钥/模型；删掉也没关系，首次运行会自动重建）
  sessions\              保存的会话（「保存会话」「新对话」「退出」时生成）
  dsh-mini-gui.log       界面日志（运行过就有）
  dsh-mini-diagnose.txt  自检/诊断输出（点过菜单 工具 里的自检/诊断就有）
  dsh-mini-error.log     崩溃日志（只有程序真的出错时才生成，出问题发这个文件）

（完整开发包还会多一个 dev\ 目录，放源码 dsh-mini.py、打包脚本、清理工具，可删，不影响使用）

如果 exe 所在目录不可写（例如放在只读共享盘、Program Files 里），
会自动改用下面的位置：

  配置文件   %APPDATA%\dsh-mini\dsh-mini.config.json
  会话记录   %APPDATA%\dsh-mini\sessions\*.json

（%APPDATA% 一般是 C:\Users\你的用户名\AppData\Roaming）


四、清空配置和对话记录
------------------------------------------------------------------------
要清的就两样（存放位置见第三章）：
  配置文件   dsh-mini.config.json
  对话记录   sessions 文件夹里的 *.json

下面命令都不写死盘符和目录，Agent 复制到任何文件夹都通用。
先对号入座：
  便携模式（绝大多数情况）-> 文件就在 exe 同目录
  只读回退模式            -> 文件在 %APPDATA%\dsh-mini\

【方法一：只用鼠标（最通用，任何版本都一样）】
  在 exe 所在文件夹里：
     - 删除 dsh-mini.config.json        -> 清空配置，下次启动重新走向导
     - 打开 sessions 文件夹，全选删除    -> 清空所有对话记录

【方法二：在 exe 所在文件夹里开命令行（通用写法，不写死路径）】
  1) 打开 exe 所在文件夹；
  2) 在资源管理器地址栏输入 cmd 回车（Win7 常用），
     或 Shift+右键 -> 在此处打开命令窗口 / 在此处打开 PowerShell 窗口；
  3) 执行（这里用的是相对路径，先切到该文件夹再执行）：

     cmd:         del dsh-mini.config.json
                  del sessions\*.json

     PowerShell:  Remove-Item .\dsh-mini.config.json
                  Remove-Item .\sessions\*.json

【方法三：清只读回退位置（路径固定，与复制到哪无关）】

     cmd:         del "%APPDATA%\dsh-mini\dsh-mini.config.json"
                  del "%APPDATA%\dsh-mini\sessions\*.json"

     PowerShell:  Remove-Item "$env:APPDATA\dsh-mini\dsh-mini.config.json"
                  Remove-Item "$env:APPDATA\dsh-mini\sessions\*.json"

【附：如果目录里带了 清理工具.cmd（完整包在 dev\ 下），双击它更省事】
  它会自动定位到 exe 所在目录（整体复制到哪都能用），按菜单选：
     1  删配置（下次启动要重新填密钥/地址/模型）
     2  删对话记录
     3  配置和对话记录都删
     4  顺带清只读回退位置 %APPDATA%\dsh-mini
     5  顺带清打包临时残留 %TEMP%\_MEI*
     0  退出
  选 1 或 3 时会再问一次 Confirm delete? [y/N]，按 y 键即可（不用按回车）。

【顺带清掉打包临时残留（可选，安全）】

     PowerShell:  Remove-Item "$env:TEMP\_MEI*" -Recurse -Force
     或者手动打开 %TEMP% 目录，删除 _MEI 开头的文件夹

【注意】
  - 命令 /clear 只清空“当前对话的上下文”，不删磁盘上的会话文件。
  - 默认**不**自动保存会话（"save_sessions": false）；保存的时机是：
    「保存会话 Ctrl+S」「新对话/切换会话」「退出程序时有内容」。
    所以 sessions 目录里只会有你主动留下来的对话，不想要就整个删掉。
  - 想恢复自动保存（每轮对话后覆盖写一份）：配置里 "save_sessions": true。
  - 会话文件是纯 JSON，包含完整对话（含工具命令和输出），
    如果对话里出现过密钥、密码等敏感内容，记得及时删除。
  - 记不清 exe 被复制到哪了？在资源管理器里搜索 dsh-mini.exe 就能找到。


五、对话的切换与管理
------------------------------------------------------------------------
图形界面下推荐用菜单：会话(S) → 新对话 / 打开会话… / 保存会话。
（「打开会话…」会列出已保存的会话：时间、模型、消息数，选中即切换；
切换前当前会话自动保存；退出程序时有内容的对话也会自动保存。）

输入框里也可以用以 / 开头的命令：

  /clear  或  /new
      清空当前上下文，相当于开一个新对话。
      磁盘上旧的会话文件不会被删除。

  /save [路径]
      把当前对话保存成 JSON。
      不写路径时保存到本次运行自己的会话文件里；
      想另存一份：/save D:\bak\我的对话.json

  /resume list
      列出最近的会话文件（最多 15 个，按时间从新到旧），前面带序号。

  /resume            （不带参数）
      恢复最近一次会话。

  /resume 3
      恢复列表里第 3 个会话。

  /resume D:\x.json
      指定文件恢复（也可以直接给路径）。

【切换对话的正确用法】
  1) 先 /resume list 看列表；
  2) 再 /resume 序号 载入；
  3) 载入后可以接着聊，程序会把新内容保存到“本次运行”自己的文件里，
     不会覆盖你刚才恢复的那个文件（想留档就 /save 另存）。

【重要提醒】
  - 恢复的只是对话历史（消息），PowerShell 的会话状态（变量、
    当前目录、后台作业）不会跟着恢复；需要时重新执行命令即可。
  - 模型名也不会跟着恢复，仍以当前配置/命令行为准。
  - 想彻底从零开始：/clear 之后再聊，或删掉 sessions 里的文件。


六、切换模型
------------------------------------------------------------------------
模型名原样发给接口，不查表、不校验。

【启动时选择（默认开启，每次启动问一次）】
  启动后先扫描接口的模型列表（GET 地址去掉 /chat/completions 再加 /models），
  然后显示成带序号的清单，例如：

     选择模型   扫描 https://api.deepseek.com/v1/models
        1) deepseek-chat            2) deepseek-reasoner
        3) gpt-4o-mini              4) qwen-plus
       ›  输入序号选择，或直接输入模型名（回车=保持 deepseek-chat）
       模型:

    直接回车  -> 用当前配置里的模型，继续
    输入序号  -> 用清单里对应的模型
    输入别的  -> 当成模型名原样使用（内测/未列出的名字直接手打）
  取不到列表也不影响：会提示一句，然后你直接手输模型名即可。
  （提示里如果出现 401，是密钥不对；出现 404，说明这个网关没有 /models 接口，
    两种情况都不影响后面的聊天功能。）

  不想每次都问：配置里 "model_picker": false，或启动加 --no-pick-model。
  想在脚本里强制弹出：--pick-model（非交互环境也生效）。

【对话中切换】
  /models          扫描并切换（和启动时同一个界面）
  /model           查看当前模型
  /model kimi-k2.6 直接切换到指定名字（不扫描）

【长期默认】
  改配置文件里的 "model": "模型名"，或启动时用 --model 模型名。

  如果名字接口不认识，会返回类似 “模型不可用：xxx” 的服务端报错，
  换回正确名字即可继续。


七、全部命令一览
------------------------------------------------------------------------
  /help              显示帮助
  /tools             列出可调用工具（pwsh、str_replace_editor）
  /config            查看当前生效配置（密钥会打码显示，末行是 pwsh 实际状态）
  /shellcheck        离线诊断 pwsh（命令跑不动时先跑这个，把结果发出来即可定位）
  /models            扫描接口可用模型并切换（也可直接输入模型名）
  /model [名称]      查看或直接切换模型
  /cwd [路径]        查看或切换工作目录（会重启 pwsh 会话并清空上下文）
  /clear  /new       清空上下文
  /save [路径]       保存会话
  /resume [list|序号|路径]   恢复会话
  /exit  /quit  /q   退出


八、键盘操作（图形界面）
------------------------------------------------------------------------
  Enter              发送消息
  Ctrl+J / Shift+Enter  输入换行（发多行消息；输入框会自动长高）
  ↑ / ↓              翻阅历史输入（多行编辑时交给光标移动）
  ← / → Home/End     左右移动光标、行首行尾
  Ctrl+V             粘贴剪贴板内容（也可直接粘贴多行文本）
  Esc                打断：停止当前模型输出 / 停止正在执行的命令（焦点在哪都管用；
                     等同点「停止」按钮）
  Ctrl+C             有选中内容=复制；没选中=清空输入；空的时候再按一次=退出
  Ctrl+D             退出程序
  Ctrl+L / F7        新对话（清空显示）
  Ctrl+S             保存会话
  Ctrl+O             打开会话（多对话切换）
  Ctrl+A             全选（输出区里可全选后 Ctrl+C 复制）
  F1                 操作指南        F2  接口与密钥
  F3                 选择模型        F4  显示/隐藏思考过程
  F5                 离线自检（82 项）  F6  pwsh 诊断
  F7                 新对话          F8  复制全部
  （自检/诊断的输出显示在独立窗口里，不会冲掉对话；
    两个窗口的内容分别写在 dsh-mini-diagnose.txt 和 dsh-mini-gui.log）


九、命令行参数（都会打开图形窗口，并自动执行对应的动作）
------------------------------------------------------------------------
  dsh-mini.exe                        打开图形界面
  dsh-mini.exe -p "问题"              开窗后自动发送这条消息
  dsh-mini.exe --setup                开窗后自动打开接口与密钥设置
  dsh-mini.exe --models               开窗后自动弹出模型选择列表
  dsh-mini.exe --selftest             开窗后自动跑 81 项离线自检
  dsh-mini.exe --shellcheck           开窗后自动跑 pwsh 诊断
  dsh-mini.exe --config D:\my.json    指定配置文件
  dsh-mini.exe --model 模型名         临时指定模型
  dsh-mini.exe --cwd D:\project       指定工作目录
  dsh-mini.exe --no-pick-model        本次启动不弹模型选择
  dsh-mini.exe --pick-model           本次启动强制弹模型选择
  dsh-mini.exe --shell-mode oneshot   强制单命令模式（每条命令一个进程，最保守）
  dsh-mini.exe --shell-timeout 60000  pwsh 单条命令超时（毫秒）
  dsh-mini.exe --no-stream            关闭流式输出
  dsh-mini.exe --no-save              不自动保存会话
  dsh-mini.exe --version              版本号
  说明：程序是无控制台的图形程序，以上参数用于脚本化/排障；
        正常使用双击即可。


十、配置文件常用字段
------------------------------------------------------------------------
文件：dsh-mini.config.json（只放需要改的字段也行）

  base_url          接口地址，例如 https://api.deepseek.com（会自动补成 .../chat/completions）
  api_key           密钥
  model             模型名
  model_picker      每次启动是否扫描模型列表让你选一次，默认 true（取消=保持当前）
  include_usage     流式也请求用量统计，默认 true（界面上能看到"缓存命中/未命中"；
                    个别老网关不认识 stream_options 会报 400，那就改回 false）
  temperature       采样温度，默认 0
  max_tokens        最大输出 token，0 表示不发送该字段
  stream            是否流式，默认 true
  request_timeout   单次请求超时秒数，默认 300
  retries           网络/限流失败重试次数，默认 3
  system_prompt     系统提示词，默认是 DSH 极简模式那句
  include_env_note  是否在提示词后追加一行运行环境说明，默认 true
  max_output_chars  工具输出截断上限，默认 16000（与 DSH 一致）
  shell_timeout_ms  pwsh 单条命令超时毫秒，默认 300000（5 分钟）
  shell_exe         指定 PowerShell 路径，留空自动探测（指定错了会提示并自动换用可用的）
  shell_mode        auto / persistent / oneshot，默认 auto（见第一章 Win7 说明）
  shell_probe_timeout_ms  长驻会话握手超时毫秒，默认 20000（老机器慢可调大）
  shell_encoding    pwsh 输出解码，auto / utf-8 / gbk / cp936
  cwd               工作目录，留空=启动时所在目录
  max_tool_rounds   单条消息最多工具调用轮数，默认 60
  show_reasoning    是否显示模型思维链（思考过程），默认 true；界面上按 F4 或
                    菜单「设置→显示思考过程」可随时切换，切换会写回配置文件
  save_sessions     是否自动保存会话（每轮写盘），默认 false；菜单/快捷键的保存、切换、退出保存不受它影响


十一、常见问题
------------------------------------------------------------------------
Q: 提示“尚未配置 api_key”
A: 运行 dsh-mini.exe --setup，或直接把密钥填进 dsh-mini.config.json。

Q: 报 401 / Invalid token
A: 密钥不对或过期；报 404 一般是地址或模型名写错。

Q: 中文显示成乱码
A: 程序已内置编码自适应；如果某个老工具输出仍乱码，可在配置里
   指定 "shell_encoding": "gbk"（或 "utf-8"）强制解码方式。

Q: 命令一直卡住
A: pwsh 工具不支持交互式输入（比如 Read-Host 会一直等）。
   默认 5 分钟超时后会杀掉会话并提示重置，下次调用会自动开新会话。
   如果每条命令都卡住，先运行 dsh-mini.exe --shellcheck 看诊断结果。

Q: Win7 上让 AI 执行命令，界面卡在 “» pwsh ...” 那一行不动
A: 这是 v1.0.0 在 Windows PowerShell 2.0 上的老毛病，v1.0.1 已修复：
   现在会自己写协议并自动降级，命令一定有结果。
   升级方法：直接用新的 dsh-mini.exe 覆盖旧的即可（配置和会话文件不用动）。

Q: Win7 上用命令时程序直接崩了（打印一段 Traceback 后退出）
A: 这是 v1.0.1 及更早在 Win7 上的编码崩溃（控制台按 cp936 严格编码，
   界面里的 » 和 › 不在 GBK 里），v1.0.2 已修复。
   如果升级后仍然崩：程序会在 exe 同目录留下 dsh-mini-error.log，
   里面是完整堆栈和当时的环境信息，把这个文件（或截图）发出来即可定位。

Q: 目录里冒出来一个 dsh-mini-error.log
A: 说明程序遇到过未预期的错误（正常使用不会生成）。里面记录了完整堆栈、
   系统版本、Python 版本、控制台编码，删掉也可以，但发出来最有帮助。

Q: 想确认这台机器上 pwsh 到底用的是哪个 PowerShell、什么模式
A: 运行 dsh-mini.exe --shellcheck（离线、不联网），会逐个列出候选
   PowerShell 的探测结果，并分别实测「持久会话」和「单命令模式」；
   在对话里也可以用 /config（末行）或 /shellcheck 看同样的信息。

Q: 命令能跑，但 AI 说变量/目录没保持
A: 说明当前是「单命令模式」（持久会话在这台机器上起不来）。
   用 --shellcheck 看降级原因；多数情况是 PowerShell 太老或被杀软/组策略限制。
   也可以在配置里把 shell_exe 指向一个确定可用的 powershell.exe 全路径。

Q: 对话太长、报上下文超限
A: 极简模式不做自动压缩（与 DSH 一致），用 /clear 开新对话，
   或 /save 存一份后用 /resume 换另一个会话。

Q: 杀毒软件报毒 / 把 dsh-mini.exe 删掉了
A: 这是 PyInstaller 单文件程序常见的启发式误报（本机出现过
   Trojan:Win32/Bearfoos.A!ml 的误判）。v1.0.1 起已经去掉了容易被误判的特征
   （不再用 base64 解码执行、不再读文件动态执行，并写入了正规版本信息）。
   若仍被拦：把 exe 所在目录加入杀软白名单，或用 dev\build-win7-exe.bat
   在本机从源码重新打包（源码 dev\dsh-mini.py 全部可查）。

Q: 想换一台机器用
A: 只复制 dsh-mini.exe 一个文件即可；把 dsh-mini.config.json
   一起复制过去，就不用重新填密钥了。

Q: token 消耗太高，有缓存吗？
A: 有。DeepSeek 系接口支持「前缀缓存」：多轮对话 + 工具调用时，
   请求开头不变的部分按约 1/10 计价，程序消息列表只追加不改写、
   系统提示词保持稳定，所以缓存天然生效。
   界面每轮回复后会显示 "缓存命中 / 未命中" 的 token 数
   （需要 "include_usage": true，默认已开）。
   换模型、改提示词措辞会让缓存失效一次，属正常。

Q: 每次启动都会弹模型选择，能不弹吗？
A: 配置里 "model_picker": false；或启动加 --no-pick-model。
   需要换模型随时按 F3（菜单 设置→选择模型）。

Q: 思维链（模型思考过程）能不显示吗？
A: 默认就显示（v1.1.4 起）；不想看按 F4（或菜单 设置→显示思考过程）切掉，
   也可以把配置里的 "show_reasoning" 改成 false。
   模型想歪了/死循环时，趁着思考内容还在刷，按 Esc 或点「停止」就能打断。
