========================================================================
 DSH 极简 Agent（dsh-mini）v1.2.0  更新说明 / 先读我
========================================================================

【这个文件夹里只有这一个程序】

  dsh-mini.exe            图形界面版（唯一版本）：双击直接出窗口，没有控制台黑框
  操作指南.txt            完整使用教程（菜单、快捷键、配置、常见问题）
  更新说明.txt            本文件
  dsh-mini.config.json    配置文件（可删；不带它首次启动会引导填写）

  运行后按需生成（出了问题才需要看）：
    sessions\               保存的会话（「保存会话」「新对话」「退出」时写入）
    dsh-mini-gui.log        界面日志（界面上出现过的每一行都在这里）
    dsh-mini-diagnose.txt   自检 / pwsh 诊断的输出（点菜单「工具」时生成）
    dsh-mini-error.log      崩溃日志（只有程序真的崩了才会出现）

  整个文件夹复制到任何 Windows 机器都能跑，不需要安装 Python 或任何依赖。


【v1.2.0 变更（移除 Win7 包袱、超长文本修复、AI 自主多模态与鼠标 Agent）】

  1) 移除 Win7 全部兼容包袱：
     - 本版本专为现代 Windows 10 / 11 深度优化，彻底移除了 Win7 旧版 CRT downlevel DLL、
       PowerShell 2.0 语法限制及 cp936 控制台强制字符降级等历史包袱，运行更轻量高效。
     - 打包升级为通用 build-exe.bat，支持 Python 3.8 ~ 3.14+。

  2) 修复 BUG 1：超长文本（上万字至十万字）新字符不显示问题
     - 根因：Windows 原生 EDIT 控件默认字符上限为 32,767（32KB），超过后静默拒绝写入新字符。
     - 修复：在创建 EDIT 控件时发送 EM_SETLIMITTEXT (0x00C5) 解除默认限制（提升至最大 2GB）。
     - 实测：已完成真实 GUI 开窗 10 万字（100,000+ 字符）超长数据流压测，新字符 100% 完整显示，末尾行精准贴底对齐。

  3) 修复 BUG 2：AI 发送命令和命令结果事无巨细写到对话框导致刷屏
     - 修复：多行长脚本自动折叠摘要（仅显示前两行与行数统计），长单行截断；
     - 限制实时输出最大行数，并在命令结束时不重复输出已显示的结果，长结果精简显示首尾预览。

  4) 修复 BUG 3：AI 读写文本文件时将读写内容全部写出的问题
     - 修复：str_replace_editor 的 view 命令读取文件成功后，绝不将成百上千行文件内容倾倒至对话区，仅显示接收状态与行数；创建/编辑文件时不打印长篇文本内容。

  5) 全自主 Agent 能力（所有工具面向 AI，由 AI 自行决策调用）：
     - AI 自主读图分析（read_image）：AI 可自行读取任意本地图片（PNG/JPG/WEBP/GIF/BMP），系统自动转换为 OpenAI 视觉协议注入上下文发送给模型，大模型自主“看到”图像并分析；
     - AI 自主屏幕截图（take_screenshot）：AI 可自行截取当前 Windows 屏幕并发送给自己分析 GUI 界面；
     - AI 自主鼠标控制（mouse_control）：AI 可自行决定将鼠标移动到何处（move）、点击何处（click: 左键/右键/中键/双击/长按/释放）、上下滚动滚轮（scroll）以及查询坐标（position）。
     - 自由开关视觉支持：配置中支持 support_vision，菜单「设置」中可随时切换。


【第一次使用（三步，前两步不联网）】

  1) 菜单「工具 → 离线自检（92 项）」或按 F5
       正常结果：自检完成：92 项，通过 92 项，失败 0 项
  2) 菜单「工具 → pwsh 诊断」或按 F6
       检查命令执行功能（会实测「持久会话」和「单命令模式」两种方式）
  3) 菜单「设置 → 接口与密钥…」或按 F2：两个输入框依次弹出（接口地址、API Key），
       光标就在输入框里，直接打字或 Ctrl+V 粘贴；回车=确定、Esc=取消；
       API Key 默认打码，勾「显示密钥」可核对。两项都确定后写进 dsh-mini.config.json，
       并**自动接着弹出模型列表**（扫 /models，可直接手输；取消=保持当前）。
       然后在最下面的输入框里打字，回车发送（第一次使用全自动，不用记快捷键）。

  提示：首次启动会弹出「选择模型」列表（从你的接口扫描），取消=保持当前模型。


【v1.1.5 变更（修「设置框弹完以后整个程序点不动」）】

  用户反馈：填完网址/密钥的窗口、跳到模型列表之后，鼠标点不了任何东西、
  光标卡在"I"型上，连标题栏的 ✕ 都点不了 —— 看起来整个程序死了。

  卡住时抓现场（窗口/线程验尸）找到机制：模态对话框弹出时主窗会被禁用（正常的
  模态行为），但**如果对话框没能真正抢到前台**（本进程不在前台时系统会拒绝
  SetForegroundWindow），它就可能躲在浏览器等窗口后面 —— 用户看到的就是
  "程序点不动、✕ 也没反应"，而那个等着他的对话框在旁边或被挡住没人知道。
  再加上主窗焦点落在窗口自己身上，打字也没反应，于是"输入状态卡死"。

  修了五处：
  1) 对话框弹出时**强制置顶**（WS_EX_TOPMOST），不再依赖前台权限、绝不会被别的
     窗口盖住；关闭时撤掉置顶属性。
  2) 对话框窗口类补上**箭头光标**：以前类光标是 NULL，鼠标停在对话框空白处会一直
     保持上一个形状（I 型）—— 就是"鼠标卡死在输入光标上"的观感来源。
  3) 焦点兜底：激活消息（WM_ACTIVATE）是异步到的，会把设好的焦点顶掉；现在收到激活
     就重新把焦点交给主要控件（有列表给列表，否则给输入框），↑↓ 选模型/打字立刻可用。
  4) 对话框关掉后给主窗补一条"重设焦点"的消息（在激活尘埃落定之后执行）：焦点稳定
     回到输入框，**不用先用鼠标点一下就能打字**。
  5) 模态期间主窗标题显示"—— 请先完成弹出的对话框"，结束还原；万一对框被挡住，
     用户也知道该找什么。

  自检 80 → 81 项；GUI 端到端 38 → 48 项（新增：对话框置顶、激活后焦点仍在编辑框/列表、
  标题提示、关掉后焦点回输入框、紧接着就能发消息）。


【v1.1.4 变更（键盘、思考过程、设置流程、输出对齐）】

  1) 修「Esc 打断失效」——根因找到了：代码里用 self.VK_ESCAPE 但**从来没定义过**它，
     于是**每一次按键**都在第一行抛 AttributeError，被窗口过程回调静默吞掉
     （无控制台打包时 stderr 也没人看得见）。受影响的不只是 Esc，而是
     **回车发送 / F1..F8 / Ctrl+L·S·D·O / ↑↓ 翻历史全部失效**（以前只能点按钮）。
     现在常量补齐，并且快捷键出错会写 dsh-mini-error.log，不会再无声无息。
  2) 第一次使用**自动弹出设置**：填「接口地址」→ 填「API Key」→ 自动接着弹出
     **模型列表**（来自接口的 /models，也可以直接手输；取消=保持当前）。
     删掉了原来单独那一步"手输模型名"（就是会卡住的那一步）。
  3) 设置保存后**立即生效**：以前 client 把 base_url/api_key 缓存在实例里，
     改完密钥其实还在用旧的，非重启不可。现在保存即 reload。
  4) 模型**思考过程（思维链）现在看得见**：默认开启，`…` 开头实时流式显示
     （TUI 一直有，GUI 以前默认关着）。F4 或菜单「设置 → 显示思考过程」可随时开关，
     开关会写进配置文件。思考时状态栏提示"按 Esc 或点「停止」可打断"。
  5) 新增**「停止」按钮**（发送按钮左边）：Esc 之外多一个看得见、点得到的打断入口；
     运行中才可点，结束自动灰掉。Key 入框焦点在一轮结束后自动回到输入框。
  6) 修「输出多了以后视图跑到上面」：以前每次刷新都整体重设文本（把插入点和滚动条
     一起清回开头），`EM_SETSEL(-1,-1)` 的语义又是"取消选择"而不是"移到末尾"，
     于是视图被送到文章开头。现在只追加新增内容，并按"总行数 - 可见行数"精确滚到
     **下边缘**，最新一行始终贴在视口底部（三种写法都实测对比过，见开发文档）。
  7) 离线自检 73 → **80 项**（新增：快捷键常量齐全、改配置立刻生效、
     GUI 显示思维链、状态栏提示、关掉思维链不再输出等）。
  8) 开发侧新增三个工具：`dev\gui-e2e.py`（38 项 GUI 端到端，内置假网关不联网）、
     `dev\real-api-test.py`（用你自己的网关真跑一遍全流程）、
     `dev\check-constants.py`（静态检查 self.XXX 有没有漏定义——就是第 1 条那个坑）。


【v1.1.3 变更（修「密钥填不进去」）】

  1) 修 设置→接口与密钥 / F2 无法输入密钥（三个问题叠在一起，都已实测修复）：
     · 输入框弹出后键盘焦点没给编辑框（焦点落在对话框窗口自己身上），
       敲键盘一个字符都进不去 → 现在弹出即把光标放进输入框并全选原值；
     · 第二次弹框起会复用第一次的窗口过程（标签串成上一个框的、填的值写进
       已作废的返回值里）→ 现在窗口过程按类只注册一份，状态按窗口句柄隔离；
     · 点确定后对话框消息循环不退出，_on_setup 永远走不到"保存配置"那一步，
       表现就是"填完点确定什么都没发生" → 现在关闭窗口会主动叫醒循环并退出。
  2) 输入框体验：标题显示"第 N/3 步"；回车=确定、Esc=取消、Tab=切换控件；
     API Key 默认打码 + 「显示密钥」勾选框；对话框在主窗正中弹出。
  3) 输入框/选择框改成真模态：弹框期间主窗禁用，不会再叠出第二个设置流程。
  4) 模型选择框（F3）跟着一起修：以前列表框漏了通知样式，"双击列表里的模型"
     其实没反应、且从列表里选中的项会被预填的输入框内容盖掉；
     现在"手输了就以手输为准，没手输就用列表里选中的那项"。
  5) 自检从 65 项增加到 73 项（新增：窗口类只注册一次、输入框焦点在编辑框上、
     密钥字段打码、确定后 ask 会返回并带回填的值、取消返回空值、状态按窗口隔离）。
  6) 新增 dev\gui-e2e.py：GUI 端到端测试（26 项断言，可测源码也可测 exe），
     把"到底能不能打字、能不能存进配置"变成可自动验证的项。
  7) 顺手修：诊断窗口重复打开会串状态（现在一次只留一个实例）；
     "另存诊断文件"写出的内容不再出现 CRCRLF 空行；
     用 --config 指定配置文件时，F2 保存会写回那个文件（以前固定写默认位置）。

  如果你之前遇到"按 F2 之后打字没反应 / 填完密钥点确定什么都没发生"，
  换成本版即可（旧版的密钥不会被改动，配置照旧）。


【v1.1.2 变更】

  1) token 缓存：默认开启用量上报（include_usage: true），
     每轮回复后界面显示 "缓存命中 / 未命中" 的 token 数。
     多轮对话 + 工具调用时，请求前缀不变的部分走服务端前缀缓存
     （DeepSeek 系约 1/10 计价）；程序保证消息列表只追加不改写、
     系统提示词字节级稳定，缓存天然生效。
  2) 自检判据修正：不再假设 PowerShell 报错一定是英文
     （中文系统会输出"找不到路径"），避免误报失败。


【v1.1.1 / v1.1.0 变更（图形界面成为唯一界面）】

  * 单 exe：dsh-mini.exe，无控制台黑框；命令行参数
    （--selftest / --shellcheck / --models / --setup / -p）都会开窗口并自动执行。
  * 换行修复：Windows 的 EDIT 控件只认 CRLF，之前只写 \n 导致
    "模型回复和命令执行之间没有回车"。已修复，块与块之间还有空行。
  * 菜单栏（常驻，不占对话区）：
      会话(S)：新对话 Ctrl+L / 打开会话 Ctrl+O / 保存会话 Ctrl+S / 复制全部 F8 / 退出 Ctrl+D
      工具(T)：离线自检 F5 / pwsh 诊断 F6 / 打开诊断日志 / 打开界面日志 / 清空界面日志
      设置(C)：选择模型 F3 / 接口与密钥 F2 / 打开工作目录
      帮助(H)：操作指南 F1 / 关于
    自检和诊断的输出**只进独立窗口**（并写入 dsh-mini-diagnose.txt），不冲掉对话。
  * 快捷键（沿用命令行版手感）：
      Esc 打断当前输出/停止命令；Enter 发送；Ctrl+J 或 Shift+Enter 换行；
      ↑↓ 翻历史；Ctrl+C 复制/清空/再按退出；Ctrl+D 退出；Ctrl+L 新对话；
      Ctrl+O 打开会话；F1..F8 见菜单。
  * 模型选择修复：F3 弹出模型列表（自动扫描 /models）+ 可直接手输；
    之前 GUI 里模型选择是坏的。
  * 多对话切换：会话菜单「打开会话…」列出已保存会话（时间/模型/消息数），
    选中即切换；切换/退出前当前会话自动保存。
  * 输入框多行自动增高；Esc 打断（停止模型输出 + 停止正在执行的命令）。
  * 默认值：show_reasoning=false（不显示思维链）、save_sessions=false
    （不自动保存每轮；保存/切换/退出仍会存）、model_picker=true（启动询问模型）、
    include_usage=true（显示缓存命中）。

【Windows 7 注意事项】

  * PowerShell 2.0 能用，但功能少、启动慢；方便的话建议装 WMF 5.1（KB3191566）。
  * 诊断窗口会告诉你这台机器用的是「持久会话」还是「单命令模式」：
    前者变量/当前目录跨调用保持；后者每条命令独立进程，兼容性最好。
  * 请确保 exe 所在目录可写；不可写时配置会自动改用 %APPDATA%\dsh-mini\。


【如果杀毒软件报毒】

  PyInstaller 打包的单文件 exe 偶尔会被杀软按启发式误判（例如
  Trojan:Win32/Bearfoos.A!ml，是机器学习误报）。本项目已刻意去掉容易被
  误判的特征（不用 base64 解码执行、不读文件动态执行、写入正规版本信息）。
  若仍被拦：把本文件夹加入杀软白名单；源码 dev\dsh-mini.py 完全公开可查，
  也可用 dev\build-win7-exe.bat 自行重新打包（开发文档见 dev\开发文档.md）。
