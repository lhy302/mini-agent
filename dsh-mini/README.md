# DSH 极简 Agent（dsh-mini）v1.2.0 - Windows 10/11 主干版本

> **单文件、零依赖、即开即用的本地 Agent —— 专注在未安装 Agent 的环境中降低安装门槛，充当全自动安装跳板**

| 项目 | 内容 |
|---|---|
| 核心定位 | **种子引导 Agent（Seed / Bootstrapper Agent）**：在干净、裸机的 Win10/Win11 环境下，通过单文件即开即用能力，自动下载、配置并安装重型 Agent 及其开发环境；亦可作为日常轻量极简 Agent 独立使用 |
| 界面 | **图形界面（唯一界面）**：菜单栏 + 对话区 + 输入框，纯 Win32 控件（ctypes），无控制台黑框 |
| 可调用工具 | 全部面向 AI 自主调用：`pwsh`（命令执行与环境配置）、`str_replace_editor`（文件查看编辑）、`mouse_control`（鼠标自主操作）、`read_image`（自主读图送入多模态分析）、`take_screenshot`（自主截屏分析 GUI） |
| 接口协议 | 支持 OpenAI Chat Completions（文本与 Vision 多模态图片格式），可自由开启/关闭视觉支持 |
| 运行环境 | Windows 10 / Windows 11（64 位），已完全剥离旧版 Win7 历史兼容包袱，**目标机器无需安装 Python、无需任何依赖** |
| 源码 | 单文件 `dev/dsh-mini.py`，只用 Python 标准库，无第三方依赖，无网络回传 |

---

## 一、为什么需要本版本？

在一台全新的电脑或未配置任何开发环境的 Windows 10 / Windows 11 系统中，想要安装诸如 DSH 完整版、Claude Code、各类重型开发 Agent 时，往往需要面临极其繁琐的前置步骤：
- 手动去官网下载安装 Node.js 或 Python 最新版；
- 手动配置系统 PATH 环境变量；
- 手动安装 Git、设置 npm 镜像与代理；
- 命令行中解决一堆环境报错和权限问题。

**`dsh-mini` 彻底打破了这个门槛**：
1. **零门槛双击即用**：把 `dsh-mini.exe` 拷到新电脑上，直接双击运行，填入 API Key 就能开始对话。
2. **AI 自主引导安装**：你可以直接对它说：
   > *“帮我在这台电脑上下载并安装配置 DSH 完整版环境”*  
   > *“帮我在这台机器上静默安装 Node.js、Git 并配置好 npm 镜像”*
3. **闭环执行**：`dsh-mini` 会自主调用自带的 `pwsh` 会话与网络下载能力，自动拉取安装程序、静默执行安装、刷新环境变量，**由它来当安装引导员，帮你全自动装好真正的完整版 Agent**。

## 二、直接用

1. 把 **`dsh-mini.exe`** 单独复制到任意机器（U 盘、桌面都行），双击运行。
2. **第一次使用会自己弹出设置**：光标已经在输入框里，直接填「接口地址」，回车 → 填「API Key」，回车 → 自动接着弹出模型列表（来自接口的 `/models`，也可以直接手输模型名；取消=保持当前）。以后想改随时按 **F2**（或菜单 设置 → 接口与密钥）。
3. 在最下面的输入框里打字，**回车发送**。
   模型的**思考过程**会实时显示出来（`…` 开头，按 `Esc` 或点「停止」按钮打断）；正文以 `●` 开头。每轮回复后还会显示 token 用量与缓存命中情况。
   命令执行过程会实时显示：`» pwsh` + 命令 + 实时输出 + `√/× 完成/失败` + 命令真实输出。
4. 配置保存在 exe 同目录的 `dsh-mini.config.json`（便携模式；目录只读时自动改用 `%APPDATA%\dsh-mini\`）。

### 快捷键（沿用命令行版的手感）

| 按键 | 功能 |
|---|---|
| `Esc` | 打断当前输出 / 停止正在执行的命令（等同点「停止」按钮） |
| `Enter` | 发送；`Ctrl+J` 或 `Shift+Enter` 换行（可写多行） |
| `↑` / `↓` | 翻阅历史输入 |
| `Ctrl+C` | 有选中=复制；没选中=清空输入；再按一次=退出 |
| `Ctrl+D` / `Ctrl+L` | 退出 / 清空显示 |
| `Ctrl+S` | 保存会话 |
| `Ctrl+O` | 打开会话（多对话切换） |
| `Ctrl+P` | 发送图片分析（输入图片路径与提示词，以 OpenAI 视觉格式发图） |
| `F1`..`F8` | 操作指南 / 接口与密钥 / 选择模型 / **显示思考过程** / 离线自检 / pwsh 诊断 / 新对话 / 复制全部 |

### 菜单（常驻，不占对话区）

* **会话(S)**：新对话 / 打开会话… / 保存会话 / 发送图片… / 复制全部 / 退出
* **工具(T)**：离线自检（92 项）/ pwsh 诊断 / 打开诊断日志 / 打开界面日志 / 清空界面日志
* **设置(C)**：选择模型 / 接口与密钥 / 显示思考过程 / 支持图片输入（视觉开关） / 打开工作目录
* **帮助(H)**：操作指南 / 关于

完整用法见 **`操作指南.txt`**；本版改动见 **`更新说明.txt`**。

## 三、这个目录里有什么

| 文件 | 作用 |

## 四、从源码打包

需要 **Python 3.8 ~ 3.12**：

```bat
cd dev
build-exe.bat
```

脚本会自动调用 PyInstaller 按 `dev\dsh-mini.spec` 打成单文件无控制台 exe，输出到本目录。
